# 🎨 ReadQuest UI & Animation Guidelines

**Version 1.0**

---

# Why This Document Exists

This document defines the visual identity and animation language of ReadQuest.

ReadQuest is not a dashboard.

It is not an AI tool.

It is not an online textbook.

It is a place for reading.

Everything should quietly disappear behind the story.

---

# Design Philosophy

The interface should feel like

Entering a quiet library.

Sitting beside a campfire.

Opening a favorite novel.

Beginning a new journey.

Never

Opening software.

Managing tasks.

Studying for an exam.

---

# Typography

Typography is the most important visual element.

The interface should never compete with text.

Reading font should

Be highly readable.

Support long reading sessions.

Provide generous line height.

Provide comfortable paragraph spacing.

Never look compressed.

---

# Reading Width

Desktop

60–80 characters per line.

Tablet

Book-like layout.

Mobile

Single-column immersive reading.

Never allow paragraphs to stretch across the full screen.

---

# Spacing

Whitespace reduces cognitive load.

Spacing should create breathing room.

Never fill empty areas just because space exists.

---

# Color Philosophy

Colors communicate meaning.

Never decoration.

Primary colors should represent

Focus

Success

Progress

Companion

Warnings

Avoid excessive grammar coloring.

The learner should focus on meaning,

not colors.

---

# Reading Modes

ReadQuest supports multiple reading modes.

## Pure Reading

Only the text.

No chunks.

No grammar.

No AI.

Maximum immersion.

---

## Chunk Reading

Meaningful chunks appear.

The reading rhythm becomes visible.

Grammar remains hidden.

---

## Grammar Mode

Grammar appears only after learner request.

Never automatically.

---

## Companion Mode

The dragon becomes more active.

Useful for beginners.

Available themes

---

# Chunk Display

Chunks should feel natural.

Never resemble syntax trees.

Separator

/

should remain visually subtle.

Chunks should guide breathing,

not grammar analysis.

---

# Reading Toolbar

Appears only after text selection.

Contains

Explain

Grammar

Translate

Image

Listen

Save

Nothing more.

Toolbar disappears automatically.

Never blocks the current sentence.

---

# Companion Placement

The dragon always remains in the same corner.

Never follows the cursor.

Never floats across the page.

Never blocks content.

Its movements should feel natural,

like a companion sitting nearby.

---

# Motion Philosophy

Animations should communicate emotion.

Never attract unnecessary attention.

Every animation has a purpose.

---

# Animation Timing

Tiny Interaction

100–150ms

Hover

150–200ms

Button Press

150–250ms

Selection

200ms

Reading Highlight

300ms

Success Feedback

600–900ms

Page Transition

250–400ms

Book Transition

500–800ms

Long animations should never delay reading.

---

# Micro Interactions

Hover

Gentle scale.

Soft shadow.

Click

Soft ripple.

Sentence Selection

Subtle highlight.

Chunk Hover

Gentle background fade.

Dragon Hover

Blink.

Tail movement.

Small smile.

Nothing exaggerated.

---

# Reading Animation

Current sentence

Soft highlight.

Current chunk

Soft glow.

Current paragraph

Very subtle emphasis.

Never flash.

Never blink.

Never pulse continuously.

---

# Dragon Animation

Idle

Breathing.

Occasional blinking.

Tail movement.

Thinking

Looks upward.

Small sparkle.

Happy

Smile.

Tiny flame.

Excited

Small jump.

Tiny wing movement.

Never perform large repetitive animations.

---

# Success Animation

Understanding a sentence

Golden particles.

Dragon smiles.

Soft glow.

Reading Skill unlocked

Book gently shines.

Skill icon appears.

Dragon nods.

Quest completed

Map expands.

Dragon celebrates.

Soft ambient particles.

Book completed

Book closes.

Dragon sits beside it.

Journey map expands.

Never interrupt reading.

---

# Sound Design

Every sound should feel

Soft.

Natural.

Comfortable.

Examples

Page turning.

Tiny sparkle.

Campfire.

Birds.

Wind.

Dragon breathing.

Never use arcade sounds.

Never use loud reward effects.

---

# Empty States

Every empty state should encourage exploration.

Examples

No Reading Plan

↓

"Let's begin your first journey."

No Saved Expressions

↓

"Interesting discoveries will appear here."

No Finished Books

↓

"Every great journey starts with one page."

---

# Loading States

Loading should feel alive.

Examples

Dragon reading.

Dragon writing.

Turning pages.

Campfire glowing.

Avoid generic loading spinners.

---

# Error States

Errors should reduce anxiety.

Never blame the learner.

Good

"We couldn't load this page.

Let's try again."

Bad

"Request failed."

---

# Accessibility

Support

Adjustable font size.

Adjustable line spacing.

Adjustable paragraph spacing.

High contrast mode.

Color blind friendly highlights.

Keyboard navigation.

Screen readers.

Reading fonts.

Accessibility is part of good design,

not an optional feature.

---

# Emotional Goal

Opening ReadQuest should feel like

"I'm entering a peaceful place to read."

Closing ReadQuest should feel like

"I want to continue tomorrow."

---

# Final Principle

Users should remember

the story,

the reading,

and the journey.

They should forget the interface exists.
